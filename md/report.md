# 机器翻译跨度级错误检测的神经元表征分析报告

---

## 1. 课题背景与研究目标

### 💡 研究背景
目前的机器翻译（MT）质量评估模型（如 **xCOMET**）虽然能够提供精准的评分，但其内部判定错误的逻辑对于研究者而言仍是一个“黑盒”。为了提升模型的可解释性，本课题旨在拆解模型内部的决策机制。

### 🎯 核心目标
*   **识别 (Identify)**：在模型数千个神经元维度中，精准定位负责监控翻译错误的“哨兵神经元”。
*   **验证线性可读性**：探究翻译错误信息在模型隐藏层中是以何种形式存储的。
*   **分析泛化性**：研究模型在不同领域（如新闻、社交媒体）下，识别错误的神经元是否具有一致性。

---

## 2. 实验设计与技术路径

本实验采用 **线性探针 (Linear Probing)** 技术，整体流程分为五个关键阶段：

| 阶段 | 核心任务 | 技术细节 |
| :--- | :--- | :--- |
| **1. 数据清洗** | 样本筛选 | 利用 `AnnotationLoader` 加载 WMT23 手工标注数据集（ESA-1/ESA-2），严格筛选具有精准字符级坐标的样本。 |
| **2. 坐标对齐** | 标签映射 | 通过 `offset_mapping` 建立重叠判定机制，将字符级错误标签精准映射到 Token（词块）上。 |
| **3. 特征提取** | 捕获激活值 | 将序列喂入 **xCOMET-XL**，通过 Hook 技术截获第 24 层（末层）的隐藏状态，获得 2560 维激活向量。 |
| **4. 数据纯化** | 信号剥离 | 精准定位并切除原文信号，仅保留译文 Token 对应的神经元数值，以 `.pt` 格式无损保存。 |
| **5. 回归分析** | 锁定神经元 | 对 7.3 万个 Token 运行带权重平衡的 **逻辑回归**，通过回归系数（Weights）锁定核心维度。 |

---

## 3. 技术难点与解决方案

在实验过程中，我们通过深度分析解决了以下三大挑战：

### 🔍 分词边界偏移问题
*   **问题**：人类标注常因误操作导致坐标不全（如 `brullt` 而非 `brullte`）。
*   **方案**：设计 **“重叠面积判定算法”**。只要 Token 与错误区间存在任何交集即判定为错误，极大地提升了容错率。

### 📏 序列对齐错位风险
*   **问题**：xCOMET 输入包含原文，初期实验曾出现隐藏状态与标签错位的情况。
*   **方案**：实现 **“核心子串滑动窗口匹配法”**。在长序列中精准定位译文起点，确保特征与标签的“像素级”对齐。

### ⚖️ 数据极度不平衡
*   **问题**：错词样本仅占总量的 **8%**。
*   **方案**：在逻辑回归中引入 `class_weight='balanced'` 损失补偿，防止模型产生预测偏向。

---

## 4. 实验结果与核心发现

基于 **73,681** 个 Token 的全量实验，我们得到了以下关键结论：

### A. 性能指标 (Performance)
*   **Recall (1): 0.92** —— 结果惊人。证明 xCOMET 内部 **92%** 的错误信号都是线性显性存储的。
*   **Precision (1): 0.43** —— 揭示了 Transformer 的 **“信号溢出效应”**（错误信号会影响相邻 Token）及模型的高敏感性。
*   **F1-Score (1): 0.59** —— 证明了线性探针方案作为 Baseline 的强劲性能。

### B. “哨兵神经元”定位
通过权重排名，我们从 2560 个维度中成功锁定了 **Top 10** 关键神经元：

1.  **头号哨兵：Neuron #309 (Weight: 0.9704)**
    *   全模型最强的错误检测器，在各种数据规模下权重稳居第一。
2.  **角色分化**
    *   **错误探测器 (正权重)**：如 `#2208`、`#926`。
    *   **正确性哨兵 (负权重)**：如 `#1937`、`#490`。

---

## 5. 结论与展望

本研究证实了 xCOMET 对翻译错误的感知具有高度的 **稀疏性** 与 **局部性**。错误判定并不是弥散在整个网络中，而是由以 **#309** 为首的少数核心神经元高度控制。

这为后续通过 **神经元干预**（Neuron Intervention）来修正翻譯偏差、提升模型可解释性打下了坚实的实验基础。
